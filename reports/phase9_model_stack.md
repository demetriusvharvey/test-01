# Phase 9: model stack and registry

The project now has an odds-independent elastic-net logistic challenger, a pregame-only feature eligibility gate, chronological inner-season hyperparameter selection, a versioned append-only model-trial registry, matched baseline log-loss/Brier on the inner validation set, and a future-only challenger forecast log. Team-rating, calibration and fitted sharp-blend helpers remain separate shadow modules. A weekly GitHub Actions workflow attempts the preregistered studies, logs `insufficient_data` and errors, and publishes the research summaries; it never promotes a model merely because it trained.

The default elastic-net training gate requires 500 earlier eligible games, 100 validation games and three seasons. The last prior season is an **inner tuning** set, not the final untouched confirmation. All features and outcomes must have been observed at the proper times, and feature names containing market/price/odds/spread/total terms are rejected. The current NBA source-rights issue blocks its training rows. No eligible settled forward sample is available at the initial run, so no model is fitted and no accuracy or profit improvement is claimed. Each weekly run also compares frozen future challenger forecasts to baseline forecasts from the exact same observation time, records matched outcomes and exclusions, and logs the results; the [forward comparison](challenger_forward.md) remains descriptive until the preregistered evidence and holdout exist.

Still incomplete: robust gradient boosting and its nested tuning, an NFL hierarchical Bayesian QB model, lineup/minutes-weighted NBA strength, TabPFN, a validated margin-distribution model, approved calibrated ensemble, explanatory SHAP drivers, and a certified independent sharp benchmark. Installing large dependencies or downloading pretrained weights is not justified without verified data, compatible licenses and an unbiased evaluation. No champion, feature or staking status is automatically upgraded without the preregistered validation bar.
